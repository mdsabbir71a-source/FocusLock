# FocusLock 1.0.13

This update redesigns only the account entry experience while preserving the working v1.0.12 timer, blocker, permissions, and onboarding behavior.

- Replaced the crowded sign-in form with two clear first-screen actions: **Continue with Google** and **Sign up with email**.
- Removed every Skip option from authentication.
- Email sign-up now opens a dedicated account-creation screen.
- Returning users can switch to a dedicated **Log in** state from the email screen.
- Added a lightweight animated botanical welcome with drifting leaves, focus rings, a growing path, and the existing FocusLock logo.
- Added short rotating encouragement that matches FocusLock's attention and habit-building theme.
- Added smooth screen entrances, button press feedback, focused-field animation, and animated status messages.
- Kept password recovery, Google authentication, consent, privacy links, account data, selected apps, and timers unchanged.

The package remains `com.focuslock.app`, stays VPN-free and analytics-free, and must be signed with the existing production certificate for install-over updates.
