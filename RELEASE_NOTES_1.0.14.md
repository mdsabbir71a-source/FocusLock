# FocusLock 1.0.14

## One-puzzle Focus Reset gate

- Added 15 lightweight focus puzzles: pattern completion, symbol matching, number recall, visual comparison, quick arithmetic, and more.
- Exactly one puzzle appears each time FocusLock is opened while an active boundary protects selected apps.
- A successful answer opens the controls for that visit; no multi-puzzle sequence is used.
- The puzzle gate is not shown when a user opens a blocked app.
- No camera, exercise, accessibility service, VPN, analytics, or new permissions were added.
- Added subtle card entrance, success, error, haptic, and answer feedback animations.
