# FocusLock 1.0.10

## Simpler timer experience

- Replaced the hidden wheel-and-tab timer flow with two always-visible duration cards.
- Added clear `−1m`, `−10s`, `+10s`, and `+1m` controls for both Use limit and Lock length.
- Added animated digital time changes, card feedback, haptic ticks, staggered reveals, and a subtle animated Use → Lock connector.
- Updated the guided setup to point users toward the new timer controls.

## Home screen behavior

- Removed the automatic Home-screen prompt.
- Removed the Home-screen menu action, pinning code, callback receiver, and manifest entry.
- FocusLock continues to appear normally in the Android app drawer.

## Compatibility

- Package: `com.focuslock.app`
- Version code: `110`
- Version name: `1.0.10`
- Signed with the existing FocusLock production certificate for install-over updates.
- No VPN, adult-content filtering, or analytics.
