# FocusLock 1.0.15

## Simpler access

- Removed the Focus Reset puzzle gate after user feedback that it was not beneficial.
- FocusLock opens normally while an active boundary is protecting selected apps.
- Removed all puzzle UI, puzzle animations, puzzle state, and puzzle-related code.
- No new permissions or background services were added.
- App blocking, timers, authentication, onboarding, and existing animations remain unchanged.
