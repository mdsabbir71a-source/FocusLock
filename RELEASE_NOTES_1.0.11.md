# FocusLock 1.0.11

## Exact scroll timer

- Added a polished Hours / Minutes / Seconds scroll picker to both timer cards.
- Users can tap the large time or **Scroll to set exact time** to open the picker.
- Every second is selectable, including short test times such as 5 seconds.
- Kept the quick `−1m`, `−10s`, `+10s`, and `+1m` controls for small changes.
- Added a highlighted center selection, live readable preview, haptic wheel ticks, animated values, and animated Apply feedback.
- Updated onboarding so the timer spotlight opens the exact scroll picker.
- The Home-screen shortcut request remains completely removed.
