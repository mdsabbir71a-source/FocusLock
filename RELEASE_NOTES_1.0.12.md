# FocusLock 1.0.12

This update keeps the exact v1.0.11 interface and improves only the timer guide.

- The onboarding now treats the two timers as separate steps.
- After setting **Use limit**, the spotlight scrolls to and highlights **Lock length**.
- The second timer opens its own Hours / Minutes / Seconds scroll wheel.
- The guide moves to **Save & start** only after the lock length is adjusted.
- Existing users can replay the full guide from the three-dot menu.

Guide order:

1. Allow required access
2. Choose an app
3. Set Use limit
4. Set Lock length
5. Save & start

All timer cards, quick adjustment buttons, exact scroll wheels, colors, animations, selected apps, and saved settings remain unchanged from the v1.0.11 interface.
