# FocusLock 1.0.7

- Confirmed the standard Android launcher entry so FocusLock appears in the phone's app list.
- Added a one-time Android-approved prompt to place FocusLock on the Home screen.
- Added **Add to Home screen** to the three-dot menu so the prompt can be opened again later.
- Preserved all selected apps, timers, account data, and existing blocking behavior during the update.
- Signed with the existing FocusLock production certificate for an install-over update.

Android launchers control Home screen placement. If a launcher does not support Android's pin-shortcut request, users can long-press FocusLock in the app list and drag it to the Home screen, or enable **Add apps to Home screen** in launcher settings.
