# FocusLock 1.0.9

Released: 2026-08-29

## Easier focus-plan UX

- Rebuilt the main screen as a compact two-step flow: choose apps, then set the timer.
- Keeps priority and selected apps visible while placing the complete list behind an animated **Show all apps** control.
- Replaced two long timer sections with animated **Use limit** and **Lock length** tabs using the existing custom minute/second wheels.
- Added a fixed bottom **Save & start** action so users never need to hunt for the main button.
- Permission setup now shows a short 3-step progress state and disappears when required access is ready.
- Simplified the sign-in screen and moved Google sign-in to the easiest position.

## Motion and feedback

- Added staggered card entrances, animated protection status, press feedback, haptic selections, timer crossfades, and an animated selected-app state.
- Added lightweight floating botanical motion and a short leaf burst after a successful save.
- Improved first-run coach marks with a pulsing spotlight and clearer timer guidance.
- Kept the existing animated pause screen and botanical visual style.

## Compatibility and safety

- Installs over previous versions with package `com.focuslock.app` and the same production signing certificate.
- Preserves accounts, selected apps, timers, permissions, and blocking settings.
- Remains VPN-free and analytics-free.
